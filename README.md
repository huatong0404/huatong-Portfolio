# huatong-Portfolio
这是跨学科设计师 Hua Tong 的个人作品集网站，用于研究生申请、工作申请与设计实践记录。

我的背景横跨建筑与人机交互，实践涵盖空间设计、实体交互、数字制造、用户研究、游戏设计、软材料制作与插画。这个网站将不同尺度和媒介的项目整理为一条持续发展的时间线。

# 收录项目

本作品集收录了7个主要项目和6个Playground项目。包括一页额外的自我介绍。

# 网站状态

作品集目前仍在持续更新中。部分项目、首页插画和个人肖像尚在制作，页面结构、叙事与交互也会继续迭代。

# 本地查看

下载仓库后，直接打开根目录中的 `index.html` 即可浏览。为获得更稳定的图片、视频和页面跳转体验，建议通过本地静态服务器运行。

# 技术

网站使用原生 HTML、CSS 与 JavaScript 构建，没有依赖前端框架。
